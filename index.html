Inclusive Cross-Platform UX

A working hub of methods, patterns, and resources for inclusive cross-platform UX design.

About

Maintained by Young Kim, a UX designer working in inclusive cross-platform interface design. MFA in Interaction Design, School of Visual Arts.

In development, July 2026

  • Inclusive Cross-Platform Patterns

    An open-source pattern library for inclusive cross-platform UX design. Twelve patterns across the practitioner journey from empathy to validation.

  • Inclusive Design Rules

    A drop-in rules file for AI coding tools. Extends WCAG 2.2 AA enforcement with inclusive design defaults the WCAG checklist alone doesn't catch.

Available now

  • Beyond

    Original research project and integrated prototype system for inclusive cross-platform UX design. MFA thesis, School of Visual Arts, 2023.

  • Digestible UX

    A newsletter on UX practice. digestibleUX.com (opens in new tab)

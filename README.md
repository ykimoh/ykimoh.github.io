# Inclusive Cross-Platform UX

A working hub of methods, patterns, and resources for inclusive cross-platform UX design. Maintained by Young Kim.

Live at [ykimoh.github.io](https://ykimoh.github.io).

## What's here

- `index.html`, hub homepage
- `styles.css`, site styles

Plain HTML and CSS, no build step. Served via GitHub Pages from the repo root.

## Accessibility

WCAG 2.1 AA target. Tested with axe DevTools, WAVE, and manual keyboard navigation before each push.

## Linked resources

- Pattern Library, open-source patterns for inclusive cross-platform UX (in development)
- Field Guide, practitioner-facing PDF and Kindle edition (in development)
- Figma Community kits, adaptive onboarding and cross-platform consistency (in development)
- [Digestible UX](https://digestibleux.com), newsletter on UX practice
